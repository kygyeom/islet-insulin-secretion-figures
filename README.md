# Islet Insulin Secretion — Example Figure Code

> **All data in this repository are synthetic.** They are generated by arbitrary functions
> and do not reproduce any result of the manuscript.

Minimal plotting code accompanying a manuscript in preparation on how islet structure
(core vs. mixed arrangement of alpha, beta and delta cells) shapes insulin secretion.

## Figures

| Script | What it draws | Output |
|---|---|---|
| `fig_islet_structure_3d.py` | Core vs. Mix cell arrangement (3D cross-section) | `examples/islet_structure_3d.png` |
| `fig_time_series.py` | Glucose, glucagon and insulin over time, Core vs. Mix | `examples/time_series.png` |
| `fig_feature_importance.py` | Random-forest feature importance for insulin secretion | `examples/feature_importance.png` |

## Usage

```bash
pip install numpy pandas matplotlib scikit-learn
python make_synthetic_data.py     # writes synthetic_*.csv
python fig_islet_structure_3d.py
python fig_time_series.py
python fig_feature_importance.py
```
